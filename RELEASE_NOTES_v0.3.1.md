# forget it v0.3.1

New features and improvements since v0.3.0:

- **Events:** add presentations, assessments and appointments alongside homework, with all-day or timed scheduling and reminders.
- **School timetables:** import `.ics` files with recurring lessons, locations, exclusions and individual reschedules, then review the import before saving.
- **Day, Week and Month timetable views:** opens on today, with lavender lesson blocks, a separate all-day row, a current-time marker and clickable lesson details.
- **Repeating tasks and events:** daily, weekday, weekly or monthly schedules through a chosen end date. Each occurrence can be edited or completed separately.
- **12-hour and 24-hour clocks:** choose System default, AM/PM or 24-hour time in Preferences. Applies to timetable labels, deadlines, events and reminder controls.
- **Conversational assistant:** follow-up messages, short clarification questions and suggested answers, with editable suggestions and calendar-based date selection.
- **Fresh chats:** closing the assistant clears the conversation; reopening starts a new chat.
- **More reliable date handling:** app-side interpretation of simple relative dates, clearly named items and date corrections. New date-only text requests use All day instead of an invented time.
- **Higher-capability model option:** Qwen3.5 9B is available for Macs with more memory and storage.
- **Model deletion:** remove downloaded Ollama models from the app after confirmation.
- **Hide the assistant:** switch off Show study assistant to remove AI controls and setup sections from the interface.
- **Broader document input:** the assistant can read PDFs, including scanned pages, Word documents, RTF and common text formats alongside screenshots. File-size and context limits apply.
- **Simpler add menu:** one calendar-style button provides both New Task and New Event.

Build 9 remains version 0.3.1. Desktop widgets are not included in this installer; signing and installation validation remain pending. The DMG is an ad-hoc development build, not a notarized public release.
